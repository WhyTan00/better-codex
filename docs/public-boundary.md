# Public boundary

This repository contains a runnable portable host, client and relay source, contracts, project-plugin examples, and separate illustrative material. The installation is real; the synthetic demo and gallery are not runtime or account acceptance evidence.

## What is published

- Better Codex's portable installation, host supervision and public configuration interfaces.
- Generic Native integration, client persistence, reading/control coordination and diagnostic code.
- Source and patches for the separately built OpenCodex IPC integration.
- A configurable `project-overview` example and contracts for your own trusted adapters and local pages.
- Synthetic demo data and presentation assets explicitly identified as illustrative.

Official application and renderer resources are not redistributed. The installer downloads pinned resources from their original host, verifies them and prepares the local compatibility layer. Their original terms continue to apply; publication of an adapter is not a license to redistribute its provider.

## What stays outside the public tree

- Conversation transcripts, real session identifiers, personal files and raw operational logs.
- OAuth tokens, API keys, cookies, passkeys, device credentials and signing private keys.
- Private SSO, gateway, tunnel, NAS and deployment hostnames or access links.
- Production Android signing material and the maintainer's production application package.
- Private investment, agenda, travel, video, publishing and other project integrations or data.
- Scripts that control the maintainer's personal desktop runtime, routing or deployments.

Your workspace and deployment configuration, local caches, generated dependencies and account directory remain on your own installation. Official Native services remain the source for account state and execution. Better Codex does not export an account as part of the public project.

## Adapter and access responsibilities

Plugins are trusted local packages and have the host's permissions. A plugin's source system must own authorization, source revisions, idempotent writes and business data. DSH-style plugins require adaptation to the published routes, schema, imports and host contracts; private directories are not portable plugin distributions.

Tailscale Serve and the optional authenticated CVM profile protect access to an installation. People on its allowlist must be trusted to use its Codex account and enabled workspaces. Workspace checks reduce accidental cross-workspace operations; they do not create OS isolation or separate tenant accounts.

Keep credentials in protected local configuration excluded from Git. Review diagnostics, screenshots and generated bundles before sharing them. A metadata-only diagnostic event can still disclose operational identifiers; raw logs are not public release assets.

# October 15 source synchronization / 10 月 15 日源码同步

This update brings the latest applicable maintenance work into the public host, Web/PWA shell and Android sources. It is a source update on `main`, not a new signed APK or a claim that every reconnect problem is solved. The downloadable beta.9 artifacts remain unchanged.

## 同步的实现

| 范围 | 本次实现 |
| --- | --- |
| 发送 | 小体积执行元数据走独立控制路径；当前前台会话可准备只读提交凭据，宿主在真正提交时重新核对。队列、工作区、权限、连接代际、Fast 配置与消息目标约束保留。 |
| 完成与恢复 | 修正已完成轮次仍复用旧显示项的问题；恢复已确认用户消息、最终回复及此前观察到的中间过程，并保留来源和轮次边界。 |
| 本地数据 | 优先当前会话和置顶，近期预载窗口为 20；手机持久存储与内存展示分开，按需读取最近轮次。展示缓存目标上限为 10 GB，实际可用量仍受设备及系统配额约束。 |
| Android | 补齐选中会话的轻量读取、焦点请求合并、连接资源释放、输入框可视区域和受限后台启动处理；同步诊断与网络阶段统计。 |
| 图片与 PDF | 同步图片路径/预览恢复；PDF 按需加载本地 CMap 与标准字体支持，随源码保留 PDF.js 和字体的许可文件。并非任意文件格式都可预览。 |
| 排障 | 关联控制路径、下载、连接及请求阶段的耗时；有限容量保留、聚合及故障隔离。日志字段经过白名单处理，不记录提示词、附件正文、认证信息或原始错误文本。 |

已有的公开版同次提交配置复用、Home 查询并发、ACK 后队列处理、独立部署配置及插件入口继续保留。同步时另外修正了 Android 更新检查写死包名的问题，改为校验当前构建的 application ID；发送准备的事件监听及通知回调在客户端退役时解除，避免旧客户端继续被唤醒。

## 公开边界

- 只同步通用实现、合成测试数据、开源依赖及文档。私有会话、账号、部署地址、业务插件、日志、密钥和签名未进入仓库。
- 官方界面资源由使用者在本机生成；本次验证使用了本地生成的真实界面模块，它们没有提交或作为下载资产发布。
- Android 保留公开包名 `org.bettercodex.android`、可配置 HTTPS 入口和使用者自己的签名流程。私有生产 OTA 服务仍不属于公共安装器。
- 本次没有改动演示视频，也没有发布新的 APK、重启现有 Native 宿主或新增测试会话。

## 验证与复现

查看 [当前验证记录](../portable-validation.md)。源码、模拟协议、真实生成的界面模块、实体手机自然使用是不同验收层次。当前回归测试不启动模型任务。

```sh
npm test
npm run test:core
# This package is the adopter-owned OpenCodex IPC host dependency.
BETTER_CODEX_TEST_HOST_PACKAGE=/path/to/opencodex/package.json npm run test:sync
(cd source/apps/sync-gateway && go test ./...)
node scripts/test-renderer.mjs --ui /path/to/generated-ui --upstream http://127.0.0.1:4174
```

Android 按 [构建说明](../android.md) 配置 JDK/SDK 后执行 `gradle testDebugUnitTest`。未提供真实 SDK 资源的 core 测试会明确跳过相关用例；renderer 测试提供实际生成资源后执行这些检查。

## 尚未闭环

间歇性重连、长尾发送和网络失败仍需要自然请求的分段证据，不能承诺所有发送都在 1 秒内完成。实体手机的耗电、发热、OEM 后台行为、公开部署端到端登录收发及完整离线浏览仍需使用者环境验收。私有部署的历史测试结果不会自动变成这次公开源码的实体手机验收结论。

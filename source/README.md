# Maintained portable core

This directory contains the allow-listed dependency closure of the portable Mac host, official web front and synchronization observer, plus the Go relay. `export-manifest.json` identifies exact source bytes. Private deployment registries and domain adapters are excluded.

Run it through the repository's installer and `scripts/better-codex.mjs`. It intentionally fails without `WORKBENCH_CONFIG`; no maintainer runtime path is used as a fallback. The previous reference-only Android and private-plugin snapshots are superseded by this runnable Mac/PWA distribution; no official renderer or APK is redistributed here.

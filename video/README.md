# Better Codex explainer

This is a silent, caption-led 32-second product explainer for the **whytan /
Better Codex** public project. The technical claims, architecture, UI labels,
project adapters, and transitions are rendered deterministically with Remotion.
It does not use a generative video model for exact product facts.

这是 **whytan / Better Codex** 公开项目的无声字幕式 32 秒产品讲解视频。架构、
界面标签、项目适配器和转场均由 Remotion 确定性渲染，不使用生成式视频模型表达
精确产品事实。

```bash
pnpm install
pnpm typecheck
pnpm render
```

Output: `video/out/better-codex-explainer.mp4`.

# Better Codex explainer

This is a silent, caption-led 32-second product explainer. The technical
claims, architecture, UI labels, and transitions are rendered deterministically
with Remotion. It does not use a generative video model for exact product
facts.

```bash
pnpm install
pnpm typecheck
pnpm render
```

Output: `video/out/better-codex-explainer.mp4`.
